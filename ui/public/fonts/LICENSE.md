# Bundled fonts

`HackNerdFontMono-Regular.woff2` / `HackNerdFontMono-Bold.woff2`

Hack Nerd Font Mono is a patched build of the Hack typeface with glyphs from the
[Nerd Fonts](https://www.nerdfonts.com/) project.

Both licenses are permissive and allow redistribution:

- **Hack** — Hack Open Font License v2.0 / Bitstream Vera License
  - Source: <https://github.com/source-foundry/Hack>
- **Nerd Fonts (patch / glyph set)** — MIT License
  - Source: <https://github.com/ryanoasis/nerd-fonts>

The WOFF2 files in this directory are converted from upstream TTFs without modification.
